# Портативний інтерфейс для масового відмінювання ПІБ

Проста офлайнова програма для Windows. Використовує той самий `NameMorpher`, що й командний режим; інтернет і сервер не потрібні.

## Робота з Excel

1. У Excel скопіюйте діапазон **з одним стовпцем повних ПІБ** (`Прізвище Ім'я По батькові`) або **трьома суміжними стовпцями** (`Прізвище`, `Ім'я`, `По батькові`), без заголовків.
2. Натисніть **Вставити з буфера** або `Ctrl+V` у таблиці програми. Вставлення замінює попередній список.
3. Виберіть відмінок та, за потреби, прапорець **Прізвище великими літерами**. Натисніть **Відмінити всі**.
4. Натисніть **Скопіювати всі результати** та вставте до Excel. Вихід — **один стовпець**, кількість і порядок рядків залишаються незмінними, включно з порожніми рядками.

У таблиці можна двічі клацнути вихідний ПІБ і змінити його вручну. Після зміни натисніть **Відмінити всі** повторно. Якщо певний рядок спричиняє помилку, його початкове значення не втрачається, а клітинка результату підсвічується.

> Автоматичні відмінювачі можуть помилятися на незвичних прізвищах і неоднозначних іменах. Для офіційних документів вибірково перевіряйте результати. Дані залишаються на вашому ПК.

## Запуск із Python для розробника

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python -m pip install -r requirements-gui.txt
.venv\Scripts\python gui.py
```

## Портативна збірка для Windows

**Найзручніше:** запустити workflow **Portable Windows UI** у GitHub Actions або взяти ZIP-артефакт із відповідного запуску. Розпакувати ZIP повністю, запустити `UA-Morpher.exe`. Python встановлювати не потрібно, інсталятора немає.

Можна зібрати локально на Windows (Python 3.12):

```powershell
py -3.12 -m pip install -r requirements-gui.txt nuitka ordered-set zstandard
py -3.12 -m nuitka --mode=standalone --enable-plugin=pyside6 --include-package-data=pymorphy3_dicts_uk --windows-console-mode=disable --output-dir=dist --output-filename=UA-Morpher.exe gui.py
```

Потім переносити **всю папку `dist\gui.dist`**, а не один `.exe`. Режим standalone не розпаковує вкладені файли до тимчасових директорій під час кожного запуску. Він не гарантує відсутність хибних спрацювань антивіруса; для широкого розповсюдження бажані перевірена збірка, цифровий підпис коду та прозора публікація джерел.

**Альтернатива без власного `.exe`:** переносимий Python із встановленими залежностями й ярликом, який запускає `gui.py` через `pythonw.exe`. Це дозволяє обійти пакування власного виконуваного файлу, але вимагає переносити сам runtime Python та бібліотеки.

Зверніть увагу на умови ліцензій сторонніх компонентів, зокрема **PySide6 (LGPL)** та словника **pymorphy3-dicts-uk (CC BY-SA)**, якщо розповсюджуєте збірку третім особам.
